# 安全管理 - 给服务穿上防弹衣

> 让服务间通信变得安全可靠

## 一、秒懂定位（30秒版）

**这个知识解决什么问题**：
```
如何实现服务间的加密通信？
如何验证服务的身份？
如何控制服务的访问权限？
```

**一句话精华**：
```
Istio 的安全管理通过 mTLS、认证、授权三层防护，
让服务间通信像银行金库一样安全！
```

**适合谁学**：
- 关注安全的架构师
- 需要实现零信任架构的团队
- 对服务安全感兴趣的开发者

---

## 二、核心框架（知识骨架）

**核心观点**：
```
Istio 安全管理分为三层：
1. mTLS：服务间加密通信（传输层安全）
2. PeerAuthentication：对等认证（验证身份）
3. AuthorizationPolicy：授权策略（访问控制）

三层防护，让服务固若金汤！
```

**关键概念速查表**：

| 概念 | 大白话解释 | 生活比喻 | 一句话记忆 |
|------|-----------|---------|-----------|
| mTLS | 双向 TLS 加密 | 加密通话 | 服务间的秘密对话 |
| PeerAuthentication | 对等认证 | 身份证 | 验证你是谁 |
| AuthorizationPolicy | 授权策略 | 门禁卡 | 控制谁能进 |
| PERMISSIVE | 宽松模式 | 可选验证 | 可以加密也可以不加密 |
| STRICT | 严格模式 | 强制验证 | 必须加密通信 |
