# Istio 服务网格实验说明

## 📋 实验概述

本实验在远程 Kubernetes 集群上部署了 Istio 服务网格，并使用 BookInfo 示例应用展示了 Istio 的核心功能，包括服务网格部署、流量管理、版本控制和金丝雀发布等。

## 🎯 实验目的

1. 演示 Istio 服务网格的部署和配置
2. 展示 Sidecar 自动注入机制
3. 演示流量管理和路由控制
4. 展示版本管理和金丝雀发布
5. 验证服务网格的可观测性

## 🚀 实验步骤

### 步骤 1: 清理集群资源

清理远程 Kubernetes 集群上的旧资源，为 Istio 部署做准备。

```bash
# 删除不需要的命名空间
kubectl delete namespace argo-rollouts argocd devops monitoring service-test tekton-pipelines-resolvers
```

### 步骤 2: 创建部署目录结构

在本地创建 Istio 部署相关的目录和文件。

```bash
mkdir -p Allen/k8slearn/istio/deployments/{install,examples/bookinfo,gateways,virtualservices,destinationrules}
```

### 步骤 3: 下载 Istio

在本地下载 Istio 1.20.0 版本。

```bash
curl -L --retry 3 --retry-delay 5 --connect-timeout 30 \
  -o /tmp/istio-1.20.0-linux-amd64.tar.gz \
  https://github.com/istio/istio/releases/download/1.20.0/istio-1.20.0-linux-amd64.tar.gz

tar -xzf /tmp/istio-1.20.0-linux-amd64.tar.gz -C /tmp/
```

### 步骤 4: 配置 Istio 安装脚本

创建 [install.sh](deployments/install/install.sh) 脚本，配置镜像源和安装参数。

```bash
#!/bin/bash
set -e

ISTIO_VERSION="1.20.0"
NAMESPACE="istio-system"
PROFILE="demo"

# 使用本地安装包
cd /tmp/istio-${ISTIO_VERSION}

# 安装 Istio
./bin/istioctl install --set profile=${PROFILE} \
  --set values.pilot.image=pilot:1.20.0 \
  --set values.global.imagePullSecrets=[] \
  -y
```

### 步骤 5: 部署到远程服务器

使用 [deploy-to-remote.sh](deployments/deploy-to-remote.sh) 脚本将部署文件传输到远程服务器。

```bash
./deploy-to-remote.sh
```

### 步骤 6: 导入 Istio 镜像

在远程服务器上导入 Istio 镜像到 containerd。

```bash
ssh root@182.42.82.135
cd /root/istio-deployments/install
./import-images.sh
```

### 步骤 7: 安装 Istio

在远程服务器上执行安装脚本。

```bash
cd /root/istio-deployments/install
./install.sh
```

### 步骤 8: 部署 BookInfo 应用

部署 BookInfo 示例应用到 bookinfo 命名空间。

```bash
# 创建命名空间并启用自动注入
kubectl create namespace bookinfo
kubectl label namespace bookinfo istio-injection=enabled

# 部署应用
kubectl apply -f /root/istio-deployments/examples/bookinfo/
```

### 步骤 9: 配置 Gateway 和 VirtualService

配置 Istio Gateway 和 VirtualService 以启用外部访问。

```bash
# 部署 Gateway
kubectl apply -f /root/istio-deployments/gateways/bookinfo-gateway.yaml

# 部署 VirtualService
kubectl apply -f /root/istio-deployments/virtualservices/bookinfo-vs.yaml

# 部署 DestinationRule
kubectl apply -f /root/istio-deployments/destinationrules/bookinfo-dr.yaml
```

### 步骤 10: 验证部署

使用 [verify-deployment.sh](deployments/verify-deployment.sh) 脚本验证部署状态。

```bash
./verify-deployment.sh
```

### 2. 流量管理展示

通过 [test-traffic-management.sh](deployments/test-traffic-management.sh) 脚本展示 Istio 的流量控制能力。

#### 场景 1: 路由到特定版本

**配置 VirtualService：**
```yaml
apiVersion: networking.istio.io/v1beta1
kind: VirtualService
metadata:
  name: reviews
  namespace: bookinfo
spec:
  hosts:
  - reviews
  http:
  - route:
    - destination:
        host: reviews
        subset: v1
```

**测试命令：**
```bash
for i in {1..20}; do
    curl -s "http://10.0.3.231:31868/productpage" | grep -o 'reviews-v[0-9]'
done | sort | uniq -c
```

**测试结果：**
```
20 reviews-v1
```

**展示内容：**
- ✅ 所有 20 个请求都路由到 reviews-v1
- ✅ 证明可以精确控制流量路由到特定版本

#### 场景 2: 50/50 流量分割

**配置 VirtualService：**
```yaml
http:
- route:
  - destination:
      host: reviews
      subset: v1
    weight: 50
  - destination:
      host: reviews
      subset: v2
    weight: 50
```

**测试结果：**
```
21 reviews-v1
19 reviews-v2
```

**展示内容：**
- ✅ 流量接近 50/50 分配（52.5% vs 47.5%）
- ✅ 证明可以实现精确的流量分割

**展示内容：**

## 🔑 关键配置文件说明

### 1. Gateway 配置

**文件**: [deployments/gateways/bookinfo-gateway.yaml](deployments/gateways/bookinfo-gateway.yaml)

```yaml
apiVersion: networking.istio.io/v1beta1
kind: Gateway
metadata:
  name: bookinfo-gateway
  namespace: bookinfo
spec:
  selector:
    istio: ingressgateway
  servers:
  - port:
      number: 80
      name: http
      protocol: HTTP
    hosts:
    - "*"
```

**说明：**
- `selector.istio: ingressgateway`: 选择 Istio 的 Ingress Gateway
- `port.number: 80`: 监听 HTTP 端口 80
- `hosts: ["*"]`: 接受所有主机名

### 2. VirtualService 配置

**文件**: [deployments/virtualservices/bookinfo-vs.yaml](deployments/virtualservices/bookinfo-vs.yaml)

```yaml
apiVersion: networking.istio.io/v1beta1
kind: VirtualService
metadata:
  name: bookinfo
  namespace: bookinfo
spec:
  hosts:
  - "*"
  gateways:
  - bookinfo-gateway
  http:
  - match:
    - uri:
        exact: /productpage
    - uri:
        prefix: /static
    - uri:
        exact: /login
    - uri:
        exact: /logout
    route:
    - destination:
        host: productpage
        port:
          number: 9080
  - match:
    - uri:
        prefix: /api/v1/products
    route:
    - destination:
        host: productpage
        port:
          number: 9080
  - match:
    - uri:
        prefix: /api/v1/reviews
    route:
    - destination:
        host: reviews
        port:
          number: 9080
```

**说明：**
- `hosts: ["*"]`: 匹配所有主机
- `gateways: ["bookinfo-gateway"]`: 关联到 Gateway
- `match.uri`: 根据 URI 路径匹配请求
- `route.destination`: 定义目标服务和端口

### 3. DestinationRule 配置

**文件**: [deployments/destinationrules/bookinfo-dr.yaml](deployments/destinationrules/bookinfo-dr.yaml)

```yaml
apiVersion: networking.istio.io/v1beta1
kind: DestinationRule
metadata:
  name: reviews
  namespace: bookinfo
spec:
  host: reviews
  trafficPolicy:
    loadBalancer:
      simple: RANDOM
  subsets:
  - name: v1
    labels:
      version: v1
  - name: v2
    labels:
      version: v2
  - name: v3
    labels:
      version: v3
```

**说明：**
- `host: reviews`: 目标服务名称
- `trafficPolicy.loadBalancer.simple: RANDOM`: 使用随机负载均衡
- `subsets`: 定义服务的子集（版本）
- `labels.version`: 根据 Pod 标签选择版本
