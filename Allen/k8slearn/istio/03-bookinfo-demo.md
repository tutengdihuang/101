# 第一个 Istio 应用 - BookInfo 示例

> 通过 BookInfo 示例，感受 Istio 的魔力

## 一、秒懂定位（30秒版）

**这个知识解决什么问题**：
```
如何部署第一个 Istio 应用？
如何观察 Istio 如何接管流量？
如何验证 Istio 的功能？
```

**一句话精华**：
```
BookInfo 是 Istio 官方示例，
通过它你能快速理解 Istio 的工作原理！
```

**适合谁学**：
- 刚安装好 Istio 的新手
- 想快速上手 Istio 的开发者
- 需要演示 Istio 功能的讲师

**不适合谁**：
- 还没有安装 Istio（先看上一篇）
- 对 Kubernetes 不熟悉（先学 K8s 基础）

---

## 二、核心框架（知识骨架）

**核心观点**：
```
BookInfo 是一个微服务应用，包含 4 个服务：
- productpage：产品页面（前端）
- details：书籍详情
- reviews：书评（有 v1、v2、v3 三个版本）
- ratings：评分

通过 BookInfo，你能学会：
- 如何部署 Istio 应用
- 如何配置流量路由
- 如何实现灰度发布
- 如何观察服务调用
```

**关键概念速查表**：

| 概念 | 大白话解释 | 生活比喻 | 一句话记忆 |
|------|-----------|---------|-----------|
| BookInfo | Istio 官方示例应用 | 样板房 | 学习 Istio 的最佳入口 |
| productpage | 前端页面服务 | 商店门面 | 用户看到的页面 |
| details | 书籍详情服务 | 商品说明书 | 提供书籍信息 |
| reviews | 书评服务 | 顾客评价 | 有三个版本 |
| ratings | 评分服务 | 打分系统 | 提供星级评分 |

**知识地图**：
```
[部署 BookInfo] → [访问应用] → [观察流量] → [配置路由] → [实现灰度发布]
```
