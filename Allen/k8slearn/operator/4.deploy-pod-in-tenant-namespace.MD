## Operator 如何“控制”这个 Pod

Tenant Operator 目前控制的是：

- `Namespace`
- `ResourceQuota`
- `RoleBinding/ClusterRole`

它不会直接改你的 Pod spec，但它通过 **配额** 和 **权限** 控制这个 namespace 里能创建多少对象、谁能操作 Pod。

### Check：查看 demo 的 resourcequota

```bash
sshpass -p '1Qaz2Wsx' ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl get resourcequota -n demo -o yaml | head -n 80'
```

### Check：查看 demo 的 rolebinding

```bash
sshpass -p '1Qaz2Wsx' ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl get rolebinding -n demo pod-admin -o yaml | head -n 80'
```
