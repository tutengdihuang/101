## Lab-05：使用阿里云镜像仓库部署 Tenant Operator（Deployment 方式）

### 目标

- 用 master 上的 `docker` 构建 `tenant-operator` 镜像
- 推送到阿里云个人版容器镜像仓库（CR）
- 在集群创建 `imagePullSecret`
- `kubectl apply -k` 部署 controller 到集群

## 2. 在 master 上构建镜像（使用阿里云 GOPROXY）

```bash
sshpass -p '1Qaz2Wsx' ssh -o StrictHostKeyChecking=no root@182.42.82.135 '
set -e
cd /root/tenant-operator

docker build -t tenant-operator:latest .
'
```

## 3. 登录阿里云镜像仓库并推送

> 注意：登录凭证不要写进仓库文档。你可以在 master 上执行 `docker login`（参考仓库根目录的 `push_all_images.sh`）。

```bash
sshpass -p '1Qaz2Wsx' ssh -o StrictHostKeyChecking=no root@182.42.82.135 '
set -e
REGISTRY="crpi-j9gshcbjtb1i6c7h.cn-hangzhou.personal.cr.aliyuncs.com"
NAMESPACE="tutengdihuang_docker_image"

docker tag tenant-operator:latest ${REGISTRY}/${NAMESPACE}/tenant-operator:latest

docker push ${REGISTRY}/${NAMESPACE}/tenant-operator:latest
'
```

---

## 4. 创建 imagePullSecret（集群侧）

> 你需要把 `<ALIYUN_USER>` / `<ALIYUN_PASSWORD>` 替换成真实值。

```bash
sshpass -p '1Qaz2Wsx' ssh -o StrictHostKeyChecking=no root@182.42.82.135 '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl create ns tenant-operator-system --dry-run=client -o yaml | KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -f -

KUBECONFIG=/etc/kubernetes/admin.conf kubectl -n tenant-operator-system delete secret aliyun-cr --ignore-not-found

KUBECONFIG=/etc/kubernetes/admin.conf kubectl -n tenant-operator-system create secret docker-registry aliyun-cr \
  --docker-server=crpi-j9gshcbjtb1i6c7h.cn-hangzhou.personal.cr.aliyuncs.com \
  --docker-username=<ALIYUN_USER> \
  --docker-password=<ALIYUN_PASSWORD>
'
```

## 5. 部署 Operator（CRD + RBAC + Deployment）

```bash
sshpass -p '1Qaz2Wsx' ssh -o StrictHostKeyChecking=no root@182.42.82.135 '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -k /root/tenant-operator/config
'
```

---

## 6. 验证 controller 是否 running

```bash
sshpass -p '1Qaz2Wsx' ssh -o StrictHostKeyChecking=no root@182.42.82.135 '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get deploy -n tenant-operator-system tenant-operator -o wide
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get pod -n tenant-operator-system -o wide
'
```

如果 `ImagePullBackOff`，通常是：
- Secret 没创建或不在同 namespace
- 仓库账号密码不对
- 镜像未 push 成功
