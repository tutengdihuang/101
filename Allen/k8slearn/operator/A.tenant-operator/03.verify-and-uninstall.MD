## 03. 验证与卸载

### 0) 变量

```bash
K8S_PASS='1Qaz2Wsx'
MASTER='182.42.82.135'
```

---

## 1) 创建 Tenant（触发 reconcile）

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -f /root/tenant-operator/config/samples/tenant_v1alpha1_tenant.yaml
'
```

---

## 2) 验证 Operator 的“控制结果”

### 2.1 验证 Tenant 状态

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get tenant demo -o yaml | head -n 120
'
```

### 2.2 验证 namespace

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get ns demo -o wide
'
```

### 2.3 验证 resourcequota

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get resourcequota -n demo object-counts -o yaml | head -n 120
'
```

### 2.4 验证 rolebinding

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get rolebinding -n demo pod-admin -o yaml | head -n 120
'
```

---

## 3) 修改 Tenant（验证幂等更新）

你可以在 master 上编辑样例文件，把 `objectCounts.services` 改小，然后重新 apply。

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -f /root/tenant-operator/config/samples/tenant_v1alpha1_tenant.yaml
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get resourcequota -n demo object-counts -o yaml | head -n 80
'
```

---

## 4) 删除 Tenant（验证 finalizer）

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl delete tenant demo
'
```

说明：该示例 finalizer 仅“放行删除”，不会主动删除 `Namespace demo`，更安全。

---

## 5) 卸载 Operator（可选）

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl delete -k /root/tenant-operator/config
'
```

如果你还想把 operator namespace 也删掉：

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl delete ns tenant-operator-system --ignore-not-found
'
```
