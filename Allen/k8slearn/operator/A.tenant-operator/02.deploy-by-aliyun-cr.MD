## 02. 部署到集群（阿里云镜像仓库）

本章节目标：

- 把 `tenant-operator` 源码上传到 master
- 在 master 构建镜像并推送到阿里云私有仓库
- 在集群创建 `imagePullSecret`
- `kubectl apply -k` 部署 CRD/RBAC/Deployment

> 所有命令使用“命令返回模式”。

---

### 0) 变量

```bash
K8S_PASS='1Qaz2Wsx'
MASTER='182.42.82.135'
REGISTRY='crpi-j9gshcbjtb1i6c7h.cn-hangzhou.personal.cr.aliyuncs.com'
ALIYUN_NS='tutengdihuang'
IMAGE_REPO='tenant-operator'
IMAGE_TAG='latest'
OP_NS='tenant-operator-system'
PULL_SECRET='aliyun-cr'
```

---

### 1) 上传源码到 master

```bash
sshpass -p "${K8S_PASS}" scp -o StrictHostKeyChecking=no -r \
/Volumes/mac_data/code/go_code/101/Allen/k8slearn/operator/tenant-operator \
root@${MASTER}:/root/tenant-operator
```

---

### 2) 在 master 构建镜像

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
set -e
cd /root/tenant-operator

docker build -t tenant-operator:latest .
'
```

---

### 3) 登录阿里云镜像仓库并推送

如果 master 上尚未登录，请先在 master 交互式执行一次：

```bash
sudo docker login --username=<YOUR_USER> crpi-j9gshcbjtb1i6c7h.cn-hangzhou.personal.cr.aliyuncs.com
```

然后推送：

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
set -e
REGISTRY="crpi-j9gshcbjtb1i6c7h.cn-hangzhou.personal.cr.aliyuncs.com"
NS="tutengdihuang"

docker tag tenant-operator:latest ${REGISTRY}/${NS}/tenant-operator:latest

docker push ${REGISTRY}/${NS}/tenant-operator:latest
'
```

---

### 4) 创建 imagePullSecret（operator namespace）

推荐方式：直接用 master 的 `/root/.docker/config.json` 生成 `dockerconfigjson` secret。

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
set -e
KUBECONFIG=/etc/kubernetes/admin.conf kubectl create ns tenant-operator-system --dry-run=client -o yaml | \
  KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -f -

KUBECONFIG=/etc/kubernetes/admin.conf kubectl -n tenant-operator-system delete secret aliyun-cr --ignore-not-found

KUBECONFIG=/etc/kubernetes/admin.conf kubectl -n tenant-operator-system create secret generic aliyun-cr \
  --type=kubernetes.io/dockerconfigjson \
  --from-file=.dockerconfigjson=/root/.docker/config.json
'
```

---

### 5) 部署 CRD + RBAC + Deployment

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -k /root/tenant-operator/config
'
```

---

### 6) 验证 controller Running

```bash
sshpass -p "${K8S_PASS}" ssh -o StrictHostKeyChecking=no root@${MASTER} '
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get ns tenant-operator-system
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get deploy -n tenant-operator-system tenant-operator -o wide
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get pod -n tenant-operator-system -o wide
'
```

如果出现 `ImagePullBackOff`，优先检查：

- `tenant-operator-system/aliyun-cr` 是否存在
- Deployment 是否引用了 `imagePullSecrets: [aliyun-cr]`
- 镜像是否 push 到了正确的 repo
