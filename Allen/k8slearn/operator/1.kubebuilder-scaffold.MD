## Lab-01：Kubebuilder 脚手架与项目结构

### 目标

- 初始化一个 Operator 项目
- 生成 API（CRD）与 Controller 框架

---

### Step 1：确认本地工具链

```sh
go version
kubebuilder version
```

### Step 2：初始化项目

```sh
mkdir -p app-operator
cd app-operator
kubebuilder init --domain example.com --repo example.com/app-operator
```

### Step 3：创建 API 与 Controller

```sh
kubebuilder create api --group apps --version v1alpha1 --kind App --resource --controller
```

### Step 4：查看生成的目录

```sh
ls -la
```

### Check

- 看到 `api/`、`controllers/`、`config/` 目录
- `make manifests` 能生成/更新 CRD

```sh
make manifests
```
