## Lab-03：部署 Tenant Operator 并验证“控制 k8s”

### Step 1：部署 CRD + Controller

> 说明：这一步只是在你的目标集群执行。本文档提供“命令返回模式”模板。

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -k /root/tenant-operator/config'
```

### Step 2：确认 operator namespace / deployment

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl get ns tenant-operator-system'
```

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl get deploy -n tenant-operator-system tenant-operator -o wide'
```

### Step 3：创建 Tenant

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -f /root/tenant-operator/config/samples/tenant_v1alpha1_tenant.yaml'
```

### Step 4：验证“Operator 控制结果”

#### Check namespace

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl get ns demo -o yaml | head'
```

#### Check resourcequota

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl get resourcequota -n demo'
```

#### Check rolebinding

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl get rolebinding -n demo pod-admin -o yaml | head'
```

### Step 5：修改 Tenant（触发 reconcile）

把 `objectCounts.services` 改小，重新 apply，然后验证 resourcequota 是否更新。

### Step 6：删除 Tenant（验证 finalizer 行为）

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl delete tenant demo'
```

> 注意：示例 finalizer 只做“放行删除”（不主动删 namespace），更安全。
