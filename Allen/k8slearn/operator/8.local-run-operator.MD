## Lab-08：本地运行 Operator 连接远程集群

### 目标

- 在本地机器运行 Operator（不是容器方式）
- 通过 kubeconfig 连接远程 Kubernetes 集群
- 实时调试 Operator 代码

---

### Step 1：准备本地环境

#### 1.1 安装 Go（如果没有）

```bash
go version
# 预期：go1.20+ 版本
```

#### 1.2 准备远程集群的 kubeconfig

本地需要能访问远程集群的 kubeconfig。有两种方式：

**方式 A：复制远程的 admin.conf 到本地**

```bash
# 在远程 master 节点
cat /etc/kubernetes/admin.conf

# 复制到本地 ~/.kube/config
# 注意：确保 IP 地址是可访问的（公网 IP 或 VPN）
```

**方式 B：使用 sshpass 代理（推荐）**

```bash
# 在本地 ~/.ssh/config 添加配置
Host k8s-master
    HostName 182.42.82.135
    User root
    Port 22
    PasswordAuthentication yes
    DynamicForward localhost:1080

# 或者直接使用 sshpass
export KUBECONFIG=/etc/kubernetes/admin.conf
```

---

### Step 2：验证集群连接

```bash
# 方式 1：直接使用 sshpass 代理
sshpass -p '1Qaz2Wsx' scp -o StrictHostKeyChecking=no root@182.42.82.135:/etc/kubernetes/admin.conf ~/.kube/config

# 方式 2：替换其中的 IP 为公网 IP
sed -i '' 's/10.0.3.231/182.42.82.135/g' ~/.kube/config

# 测试连接
kubectl get nodes
# 预期：看到 master 和 worker 节点
```

---

### Step 3：修改 Operator 使用外部 kubeconfig

更新 `main.go`：

```go
import (
	"os"
	"path/filepath"
)

func main() {
	// 使用 KUBECONFIG 环境变量指定的配置文件
	// 或者默认 ~/.kube/config
}
```

关键点：确保 `ctrl.GetConfigOrDie()` 能读取到正确的配置。

---

### Step 4：运行 Operator

```bash
cd ../tenant-operator

# 设置 kubeconfig 环境变量
export KUBECONFIG=~/.kube/config
# 或者使用远程代理
# export KUBEPROXY_PORT=1080  # 如果使用 ssh -D 代理

# 运行
go run ./cmd/main.go

# 预期输出：
# 2026-01-24T12:00:00.000Z  INFO    setup   starting manager
# 2026-01-24T12:00:00.001Z  INFO    setup   controller reconciled
```

---

### Step 5：测试 Operator

#### 5.1 创建 Tenant CR

```bash
# 在另一个终端
kubectl apply -f ../tenant-operator/config/samples/tenant_v1alpha1_tenant.yaml
```

#### 5.2 查看结果

```bash
# 应该自动创建 namespace、resourcequota、rolebinding
kubectl get namespace,resourcequota,rolebinding -l tenant.cncamp.io
```

---

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 连接被拒绝 | 检查防火墙、安全组是否开放 6443 端口 |
| 证书错误 | 使用 `kubectl --insecure-skip-tls-verify` 或导入证书 |
| 权限不足 | 确保 kubeconfig 有 cluster-admin 权限 |
| API Server 不可达 | 使用 ssh tunnel 或 VPN |
