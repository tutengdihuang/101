## 02. 脚手架与工程初始化（Kubebuilder）

> 本章节描述在本地完成代码工程初始化（不要在 master 上做本地工程生成）。

### 0) 前置

确认本地有：

```bash
go version
kubebuilder version
```

---

### 1) 初始化工程目录（建议）

在 `Allen/k8slearn/operator/` 下创建独立工程（与 A 分离）：

- 目录：`k8s-test-operator/`
- repo module（示例）：`github.com/cncamp/101/Allen/k8slearn/operator/k8s-test-operator`

---

### 2) 生成脚手架

```bash
kubebuilder init --domain cncamp.io --repo github.com/cncamp/101/Allen/k8slearn/operator/k8s-test-operator
```

---

### 3) 创建 API & Controller

```bash
kubebuilder create api --group apps --version v1alpha1 --kind K8sTest --resource --controller
```

---

### 4) 生成 CRD

```bash
make manifests
```
