## 05. 验证、升级与卸载

> 等 B 的工程与 manifests 完成后，本章补齐可直接执行命令。

### 验证建议

- `kubectl get k8stest -n <ns>`
- `kubectl get deploy,svc,cm,ing -n <ns>`
- `kubectl get pods -n <ns> -o wide`

### 升级建议

- 修改 `spec.imageTag` / `spec.replicas` 再 apply
- 观察 `rollout status`

### 卸载建议

- `kubectl delete k8stest <name>`
- 或 `kubectl delete -k config/default`
