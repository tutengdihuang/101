## 获取资源时：统一使用“命令返回模式”

你在写实验文档/做排查时，必须贴可复制的一行命令，直接返回结果（避免交互式步骤丢信息）。

### 统一模板

```bash
sshpass -p "$K8S_PASS" \
ssh -o StrictHostKeyChecking=no root@182.42.82.135 \
'KUBECONFIG=/etc/kubernetes/admin.conf kubectl get pods -n kube-system -l k8s-app=calico-kube-controllers -o wide'
```

### 约定

- 所有 `kubectl` 都显式带 `KUBECONFIG=/etc/kubernetes/admin.conf`
- 所有远程执行都走 `sshpass + ssh -o StrictHostKeyChecking=no`
- 贴命令时：能复制就跑，能跑就能复现
