## Lab-06：Webhook 实战（Validating + Mutating）

### 目标

- 为 Tenant CRD 添加 Validating Webhook（验证 CR 是否合法）
- 添加 Mutating Webhook（自动设置默认值）
- 理解 Admission Review 请求结构

---

### Step 1：启用 Webhook

在 `api/v1alpha1/tenant_types.go` 中添加注释：

```go
// +kubebuilder:webhook:path=validate-tenant-v1alpha1-tenant,mutating=false,failurePolicy=fail,groups=tenant.cncamp.io,resources=tenants,verbs=create;update;delete,versions=v1alpha1,name=validate-tenant.v1alpha1.tenant.cncamp.io
// +kubebuilder:webhook:path=mutate-tenant-v1alpha1-tenant,mutating=true,failurePolicy=fail,groups=tenant.cncamp.io,resources=tenants,verbs=create;update,versions=v1alpha1,name=mutate-tenant.v1alpha1.tenant.cncamp.io
```

重新生成代码：

```bash
cd ../tenant-operator
make manifests
```

### Step 2：实现 Validating Webhook

创建 `pkg/webhook/tenant_webhook.go`：

```go
package webhook

import (
	"context"
	"fmt"
	"net/http"

	"k8s.io/apimachinery/pkg/runtime"
	ctrl "sigs.k8s.io/controller-runtime"
	"sigs.k8s.io/controller-runtime/pkg/webhook"
	"sigs.k8s.io/controller-runtime/pkg/webhook/admission"

	tenantv1alpha1 "github.com/cncamp/101/Allen/k8slearn/operator/tenant-operator/pkg/apis/tenant/v1alpha1"
)

type TenantWebhook struct {
	Decoder *admission.Decoder
}

func (r *TenantWebhook) SetupWithManager(mgr ctrl.Manager) {
	mgr.GetWebhookServer().Register(
		"/validate-tenant-v1alpha1-tenant",
		&webhook.Admission{Handler: r},
	)
	mgr.GetWebhookServer().Register(
		"/mutate-tenant-v1alpha1-tenant",
		&webhook.Admission{Handler: &mutatingWebhook{Decoder: r.Decoder}},
	)
}

func (r *TenantWebhook) Handle(ctx context.Context, req admission.Request) admission.Response {
	tenant := &tenantv1alpha1.Tenant{}
	if err := r.Decoder.Decode(req, tenant); err != nil {
		return admission.Errored(http.StatusBadRequest, err)
	}

	if tenant.Spec.Namespace != "" {
		if len(tenant.Spec.Namespace) > 63 || len(tenant.Spec.Namespace) < 1 {
			return admission.Denied("namespace name must be between 1 and 63 characters")
		}
	}

	if tenant.Spec.AdminUser != "" {
		if tenant.Spec.AdminUser == "admin" {
			return admission.Denied("cannot use 'admin' as adminUser")
		}
	}

	return admission.Allowed("")
}

type mutatingWebhook struct {
	Decoder *admission.Decoder
}

func (r *mutatingWebhook) Handle(ctx context.Context, req admission.Request) admission.Response {
	tenant := &tenantv1alpha1.Tenant{}
	if err := r.Decoder.Decode(req, tenant); err != nil {
		return admission.Errored(http.StatusBadRequest, err)
	}

	mutated := tenant.DeepCopy()
	
	if mutated.Spec.Namespace == "" {
		mutated.Spec.Namespace = mutated.Name
	}
	
	if mutated.Spec.AdminUser == "" {
		mutated.Spec.AdminUser = "mfanjie"
	}

	if mutated.Spec.ObjectCounts == nil {
		mutated.Spec.ObjectCounts = &tenantv1alpha1.ObjectCountsQuota{
			ConfigMaps:    "20",
			Secrets:       "20",
			Services:      "10",
			LoadBalancers: "20",
			NodePorts:     "30",
		}
	}

	return admission.PatchResponseFromRaw(req.Object, mutated)
}
```

### Step 4：测试验证

#### 4.1 构建镜像

```bash
docker build -t tenant-operator:v1.0.0-webhook .
docker tag tenant-operator:v1.0.0-webhook crpi-j9gshcbjtb1i6c7h.cn-hangzhou.personal.cr.aliyuncs.com/tenant-operator:v1.0.0-webhook
docker push crpi-j9gshcbjtb1i6c7h.cn-hangzhou.personal.cr.aliyuncs.com/tenant-operator:v1.0.0-webhook
```

#### 4.2 测试 Validating Webhook

```bash
# 应该被拒绝（namespace 太长）
cat > /tmp/invalid-tenant.yaml <<EOF
apiVersion: tenant.cncamp.io/v1alpha1
kind: Tenant
metadata:
  name: test-tenant-too-long-name-exceeds-63-characters-limit
spec:
  namespace: this-is-a-very-long-namespace-name-that-exceeds-the-maximum-length-of-63-characters
  adminUser: testuser
EOF

KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -f /tmp/invalid-tenant.yaml
# 预期：被 Webhook 拒绝
```

```bash
# 应该被拒绝（不能使用 admin 用户）
cat > /tmp/invalid-admin.yaml <<EOF
apiVersion: tenant.cncamp.io/v1alpha1
kind: Tenant
metadata:
  name: test-admin
spec:
  adminUser: admin
EOF

KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -f /tmp/invalid-admin.yaml
# 预期：被 Webhook 拒绝
```

#### 4.3 测试 Mutating Webhook

```bash
# 只提供 name，自动填充 namespace 和默认值
cat > /tmp/mutate-tenant.yaml <<EOF
apiVersion: tenant.cncamp.io/v1alpha1
kind: Tenant
metadata:
  name: auto-ns-tenant
EOF

KUBECONFIG=/etc/kubernetes/admin.conf kubectl apply -f /tmp/mutate-tenant.yaml
KUBECONFIG=/etc/kubernetes/admin.conf kubectl get tenant auto-ns-tenant -o yaml
# 预期：自动填充了 spec.namespace=auto-ns-tenant 和默认值
```

### 扩展思考

1. **更多验证规则**：添加对 namespace 命名规范的验证（RFC 1123）
2. **条件修改**：Mutating Webhook 中根据不同场景设置不同默认值
3. **策略模式**：验证失败时是 Deny 还是 Warn（Audit）
